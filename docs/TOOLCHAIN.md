Package Manager builds need no network access to third-party repositories.

## GitHub Actions

Runner images (September 2026): `ubuntu-24.04` (JDK 17 default + 21/25,
Android SDK platforms up to 37, build-tools 36/37, NDK 27.3/28.2/29.0, KVM for
emulators), `windows-2025` (VS 2022 Enterprise 17.14, Inno Setup 6.7.1),
`macos-26` (arm64; Xcode 26.6 default, also 26.0.1-26.5; Ruby 3.4, CocoaPods
1.17).

`actions/cache@v5` by tag (not by SHA); that nested reference is outside this
repository's control.

To update a pin: `git clone --depth 1 --branch <tag> https://github.com/<owner>/<action>`,
review the diff, take `git rev-parse HEAD`, and replace SHA and comment in both
workflows and in this table.
