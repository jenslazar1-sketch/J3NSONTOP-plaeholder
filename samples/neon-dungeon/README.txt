NEON DUNGEON (sample)
=====================

This workspace was generated by J3NSONTOP on first run so every tool has real
files to work on right away. "Neon Dungeon" is a fictional game invented for
these samples; nothing here belongs to a real game.

Everything is disposable: edit it, break it, apply mods to it. Resetting the
sample workspace (Workspaces section) regenerates the original files, and
removing it deletes only this app-owned copy.

WHAT'S INSIDE
-------------
  game/          the "installed game" that mod profiles are applied to
    game.json      identifies the target: neon-dungeon 1.4.2
    config/        settings.ini, graphics.json, controls.yaml, balance.toml
    data/          items.csv, enemies.tsv, HUD layout, English UI strings
    saves/         slot1.json + save.schema.json for the save-data editor
    sprites/       hero_walk.png (4x2 frames of 32x32) and six item icons
    textures/      logo.png (256x128 with transparency)
    logs/          game.log (~300 lines) and a crash report
  downloads/     the 7 sample mod packages (.j3mod); already imported into
                 this workspace's mod library together with 4 profiles
  duplicates/    exact copies (and one near-copy) for the duplicate finder
  rename-demo/   badly named files for the batch renamer
  notes/         a to-do list and a file with a Unicode name
