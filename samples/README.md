# Samples (generated)

Everything in this folder is generated by `dart run tool/export_samples.dart` from
`lib/features/sample/sample_content.dart`. Do not edit these files by hand: change the
generator and run the tool again. The output is byte-for-byte deterministic and
`SHA256SUMS.txt` lists every file (`cd samples && sha256sum -c SHA256SUMS.txt`).

"Neon Dungeon" is a fictional game invented for these samples. All content is CC0-1.0.
The app creates the same content as its disposable sample workspace on first run
(see `docs/SAMPLES.md`); package and profile formats are in `docs/MOD_FORMAT.md`.
